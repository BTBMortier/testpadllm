# Gherkin-to-Python LLM Compiler & Terminal Text Editor

This project is an experimental, LLM-driven development pipeline that compiles Gherkin feature specifications (`.feature` files) directly into executable Python code. The target application generated by this compiler is a fully functional, terminal-based text editor built using Python's `curses` library.

## Project Architecture

The project is divided into two main parts:
1. **The Compiler (`compiler.py`)**: A script that reads Gherkin specifications, sends them to a local LLM (e.g., Ollama, LM Studio, or vLLM) using the OpenAI API client, cleans up the generated code, formats/lints it using `ruff`, and saves it to the target paths.
2. **The Specifications (`specs/`)**: Gherkin feature files describing the behavior of the terminal text editor:
   - `specs/01.feature` ➔ `src/config.py` (Configuration constants)
   - `specs/02.feature` ➔ `src/buffer.py` (Text buffer state and operations)
   - `specs/03.feature` ➔ `src/ui.py` (Terminal UI rendering and input handling)
   - `specs/04.feature` ➔ `main.py` (Main application entrypoint)

## Getting Started

### Prerequisites

- **Python 3.10+**
- **Ruff** (for code formatting and linting):
  ```bash
  pip install ruff openai
  ```
- **Local LLM Server**: A running instance of an OpenAI-compatible API server. By default, `compiler.py` is configured to use **Ollama** with the `qwen2.5-coder:7b` model:
  - URL: `http://localhost:11434/v1`
  - Model: `qwen2.5-coder:7b`
